Project policies
================

Development and release policies are maintained with the source repository:

* `Contributor guide <https://github.com/diliadis/DeepMTP/blob/main/CONTRIBUTING.md>`_
* `Changelog <https://github.com/diliadis/DeepMTP/blob/main/CHANGELOG.md>`_
* `Migration guide <https://github.com/diliadis/DeepMTP/blob/main/MIGRATION.rst>`_
* `Security policy <https://github.com/diliadis/DeepMTP/blob/main/SECURITY.md>`_
* `Release checklist <https://github.com/diliadis/DeepMTP/blob/main/RELEASING.md>`_

Report ordinary bugs and feature requests through the
`public issue tracker <https://github.com/diliadis/DeepMTP/issues>`_. Potential
security vulnerabilities should follow the private reporting instructions in
the security policy.
