DeepMTP.runtime package
=======================

The runtime namespace owns numerical training and evaluation, experiment
persistence, lifecycle presentation, reporting integrations, and structured
evaluation progress:

.. code-block:: python

   from DeepMTP.runtime import (
       Evaluator,
       ExperimentStore,
       ProgressObserver,
       TensorBoardReporter,
       TrainingEngine,
   )
